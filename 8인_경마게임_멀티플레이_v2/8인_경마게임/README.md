# 천마 경마장 — 8인 멀티플레이 v2

## v2 적용 사항
- 공개 로비 / 비공개방 + 비밀번호 / 초대코드
- 방 최대 28명, 주자 8명, 관전자 20명
- 계정 등록/로그인 + 서버 JSON 영속 저장
- 로그인 계정은 하루 1회 2,000 코인 지급
- 주자 참가비 100, 1~3위 400/250/150
- 관전자 1경기 1회, 최대 500 코인 배팅
- 배팅 풀의 5% 수수료를 1위 주자에게 지급
- 승리 말에 건 관전자에게 나머지 풀을 베팅액 비율로 배분하는 풀 배팅 방식
- 5바퀴 타원형 트랙
- 5종 날씨 + 비/눈/폭우 시각 효과
- 8마리 고유 필살기 + 중2병 대사
- 필살기 쿨다운
- 매우 낮은 확률의 말 전복/기수 부상 이벤트
- 10분 컨디션 갱신
- 실시간 Socket.IO 채팅
- 채팅의 사용자별 언어 표시 구조 + 선택적 자동번역 API 연결
- 부드러운 Canvas 애니메이션
- 모바일 반응형 UI

## 로컬 실행
Node.js 20 이상:

```bash
npm install
npm start
```

브라우저: http://localhost:3000

## Render 공개 배포
1. GitHub에 프로젝트 업로드
2. Render → New → Web Service
3. Repository 선택
4. Build Command: `npm install`
5. Start Command: `npm start`
6. 배포 후 Render가 발급한 `https://....onrender.com` 주소 사용

## 자동번역
채팅은 `translations` 객체를 통해 사용자별 언어를 표시하도록 설계되어 있습니다. 실제 번역을 켜려면 서버 환경변수 `TRANSLATE_API_URL`에 LibreTranslate 호환 번역 API 엔드포인트를 지정하면 됩니다. 지정하지 않으면 원문을 표시합니다.

## 데이터
`data.json`에 계정과 코인이 저장됩니다. 단일 서버 프로토타입용입니다. 실제 서비스에서는 PostgreSQL/Redis 등의 DB와 서버 권위형 검증을 권장합니다.

## 서비스 전환 시 추가 권장
- PostgreSQL 계정/코인 DB
- Redis 또는 Socket.IO adapter
- 서버 권위형 레이스/배팅 검증
- 운영자 패널 / 신고 / 제재
- rate limit / anti-cheat
- CDN 및 이미지/스프라이트 저장소
- 모바일 최적화
- 실제 도트 스프라이트 애니메이션
- 실제 번역 서비스 및 캐시
- 법률 검토

현재 코인은 가상 게임 재화이며 현금 환전 기능은 없습니다. 실제 금전 또는 현금성 보상을 걸게 만드는 경우에는 적용 지역의 게임물·도박·결제·연령 관련 규정을 별도로 검토해야 합니다.
